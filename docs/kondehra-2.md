Режим «Перед отплытием» проверяет дела текущего визита. [Как считается прогресс](departure-progress.md) «Пропущено» требует подтверждённого закрытия ветки. Местоположение учитывается для оценки текущего доступа. Сам по себе переход на корабль не закрывает задания. Пока разведка активна, `DIA_GERNOT_KONDEHRAZURUECK` позволяет вернуться. Позже Кондеру может предложить Болдуин в `DIA_BALDWIN_SEEFAHRT`.

Статус определяется из флагов, реально присваиваемых в перечисленных ветках, и совпадающей темы журнала. Отсутствие нужных данных, неоднозначность журнала и недоказанный доступ к предмету дают «Не удалось определить». Для предметов читается только доступный в памяти список инвентаря. Содержимое сундуков, упакованные предметы и все альтернативные точки начала вне Кондеры требуют отдельного подтверждения. Нулевой флаг сам по себе не доказывает пропуск.
