# Odyssee Quest Inspector

Union-плагин для Gothic II: Ночь Ворона (Windows x86). Открывает отдельный журнал экспедиции со списком заданий, статусами и подсказками. Показывает задания «Альбатроса», Кондеры и Таморы во второй главе русской «Одиссеи» 2.7.5.2, включая задания, которые ещё не появились в журнале. При первом открытии после загрузки инспектор выбирает корабль или остров по локации игрока. [Каталог «Альбатроса»](docs/albatros-2.md) · [Каталог Кондеры](docs/kondehra-2.md) · [Каталог Таморы](docs/tamora-2.md)

## Управление

| Клавиши | Действие |
|---|---|
| Апостроф `'` | Открыть или закрыть журнал |
| Esc | Закрыть журнал |
| ↑ / ↓ | Выбрать задание |
| PgUp / PgDn | Перелистнуть список |
| ← / → или Shift+T | Переключить «Кондеру», «Альбатрос» и Тамору |
| Enter или Shift+H | Показать или скрыть подсказку выбранного задания справа |
| Shift+↑ / Shift+↓ | Прокрутить длинную подсказку |
| Shift+F | Сменить фильтр |
| Shift+V | Переключить список дел текущего визита «Перед отплытием» |
| Shift+D | Перейти к диагностике флагов или вернуться к заданиям |
| ← / → или PgUp / PgDn | Перелистнуть страницу диагностики |
| R | Перечитать данные |

Процент наверху относится к подтверждённым делам текущего визита. Местный этап длинной цепочки засчитывается по своим условиям. Пропущенные и неясные дела вынесены в отдельные счётчики. [Как считается прогресс](docs/departure-progress.md)

Подсказки скрыты при открытии окна. Смена задания, фильтра или острова снова скрывает подсказку.

Пока журнал открыт, мир стоит на паузе. Игра продолжится после закрытия журнала.

## Сборка и установка

В [Actions](https://github.com/piratvasyamorexod-alt/OdysseeQuestInspector/actions) выберите успешную сборку своего коммита и скачайте `OdysseeQuestInspector-G2A-Union`. Для локальной сборки запустите `Build-Windows.ps1` с Visual Studio 2022, CMake и Git. Скрипт использует закреплённую ревизию шаблона Union и помещает пакет в `release/OdysseeQuestInspector.vdf`.

Перед игровым тестом сделайте резервную копию сохранений. Закройте игру. Если прежняя версия инспектора установлена, уберите её из `Gothic II/Data` и положите туда новый VDF. Для удаления закройте игру и уберите VDF из этой папки. Пакет содержит DLL плагина и требуемую шаблоном `UnionAPI.dll`. Нужен Union. Плагин читает состояние игры и выводит журнал через игровой интерфейс.

## Проверка

- CI проверяет переходы статусов на синтетических состояниях, затем собирает Win32 VDF.
- Откройте журнал на корабле, Кондере и Таморе. Проверьте автовыбор локации, переключение стрелками и закрытие через Esc. На Таморе пройдите лист стрелками и PgUp/PgDn, затем примените фильтр.
- Откройте журнал рядом с движущимся NPC. Убедитесь, что останавливаются NPC и игровые часы, а стрелки и Enter работают. Закройте журнал через Esc, затем повторите через апостроф. В обоих случаях мир должен снова двигаться.
- В карточке справа нажмите Enter. Проверьте, что подсказка скрыта при открытии журнала и смене задания, а слева при её показе сохраняются позиции названий и статусов. Длинную подсказку прокрутите через Shift+↑/↓. Сделайте одно дело и проверьте счётчик, затем откройте список Shift+V. Проверьте Shift+D, стрелки и R.
- Загрузите второе сохранение с открытым окном, затем начните новую игру и смените локацию. Окно должно закрыться на загрузке и показывать актуальные данные при следующем открытии.
- Для веток пропуска проверьте на отдельном сохранении отказ от крыс или посоха. Другие задания сохраняют собственный статус при переходе на корабль. Если русский текст искажён или есть конфликт клавиш, запишите версию Union, рендерер и комбинацию клавиш, на которой это произошло.
